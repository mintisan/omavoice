# Changelog

All notable OmaVoice changes are recorded here.

## 0.1.0 - 2026-08-23

- Initial independent Omarchy Linux pre-release.
- RC003 ATVV audio to a stable 16 kHz PipeWire source.
- Pinned Handy integration for local/API speech-to-text and global text insertion.
- Safe keyd mappings and configurable keyboard shortcuts through a fixed PolicyKit helper.
- OmaVoice tray and settings UI with English default and Simplified Chinese locale support.
- Private aggregate usage statistics and an optional, separately stored transcript archive.
- Source-pinned Arch x86_64 binary bundle and tag-driven GitHub Release pipeline.
